RUVA DETAILING - WEB SITESI (Ilk Surum)

Dosyalar:
- index.html: Kurumsal ana sayfa
- randevu/index.html: Mevcut randevu sistemini yeni alan adinda gosteren gecici entegrasyon
- CNAME: GitHub Pages ozel alan adi

YAYINLAMA
1. GitHub'da mustafakaraapca-collab/ruvadetailing-web deposunu ac.
2. Bu paketteki index.html, CNAME ve randevu klasorunu deponun ana dizinine yukle.
3. Settings > Pages > Build and deployment > Deploy from a branch, main, /(root), Save.
4. Custom domain: ruvadetailing.com
5. Natro'da DNS A kayitlarini @ hostuyla GitHub Pages IP'lerine ayarla:
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
Opsiyonel: www CNAME => mustafakaraapca-collab.github.io
6. DNS yayildiktan ve sertifika hazirlandiktan sonra Enforce HTTPS'i etkinlestir.

ONEMLI
Mevcut yonetim sistemi hic degistirilmedi.
Randevu iframe yoluyla mevcut GitHub Pages ekranindan yuklenir.
Bazı mobil tarayicilarda 3. taraf depolama / iframe sinirlamalari randevu durumu takibini
engelleyebilir. Böyle durumda formun sag altindaki yeni sekmede ac baglantisini kullanin.
Bu gecici cozumdur: sonraki surumde orijinal randevu.html dosyasi yerel /randevu/
altina tasinarak iframe kaldirilmalidir. Canli randevu olusturma ve durum takibi
Natro domaini uzerinden gercek kullaniciyla test edilmelidir.

Fotograflar temsili Unsplash gorselleridir; isletmenin gercek isleri degildir.
Kesin isletme adresi, telefon ve orijinal kurumsal logo tarafimizda olmadigindan
sitede uydurma bilgiler kullanilmamistir.
